# ⚡ Диспетчер задач Windows — 3D Интерактивная Презентация

Красивая, детализированная и полностью интерактивная 3D-презентация о **Диспетчере задач Windows**.

![Preview](https://images.unsplash.com/photo-1518770660439-4636190af475?w=1200&q=80)

## ✨ Особенности

- **Полноценная 3D-сцена** на Three.js с плавающими объектами, частицами, освещением и тенями
- **7 больших разделов** с большим количеством текста:
  1. Главная (Hero)
  2. История (от Windows 3.0 до Windows 11)
  3. Ключевые возможности
  4. Подробный разбор всех вкладок
  5. Как открыть Диспетчер задач (6 способов)
  6. Полезные советы и трюки
  7. Глубокий технический разбор + Будущее
- Плавающие 3D-детали, динамическое освещение, glow-эффекты
- Адаптивный дизайн (мобильные / планшеты / десктоп)
- Плавные анимации при скролле
- Интерактивные вкладки, tilt-эффект карточек
- Счётчики статистики
- Готово к загрузке на GitHub Pages

## 🚀 Как запустить

1. Скачайте или клонируйте репозиторий
2. Откройте `index.html` в современном браузере
   - Или поднимите локальный сервер:
     ```bash
     # Python
     python -m http.server 8000

     # Node.js
     npx serve .
     ```
3. Откройте http://localhost:8000

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — градиенты, backdrop-filter, анимации, CSS Grid / Flexbox
- **Vanilla JavaScript** — без фреймворков
- **Three.js r128** — 3D-графика (CDN)
- **Google Fonts** — Orbitron + Inter

## 🌐 GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Settings → Pages → Source: Deploy from a branch → `main` / root
4. Сайт будет доступен по адресу `https://ваш-логин.github.io/название-репо/`
