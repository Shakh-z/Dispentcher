# ⚡ Диспетчер задач Windows — 3D Интерактивная Презентация

Красивая 3D-презентация о Диспетчере задач Windows.

## ⚠️ ВАЖНО — Как правильно загрузить на GitHub Pages

### Вариант 1 (САМЫЙ ПРОСТОЙ — рекомендуется)

1. Возьми файл **index.html** (он уже содержит все стили и скрипты внутри)
2. В репозитории GitHub удали всё старое
3. Загрузи **только один файл** index.html в корень репозитория
4. Settings → Pages → Source: Deploy from a branch → main → / (root)
5. Подожди 1–2 минуты и обнови страницу (Ctrl+F5)

Готово. Сайт будет работать полностью (3D, анимации, стили).

### Вариант 2 (с папками)

Если хочешь структуру с папками:

```
/
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
```

**Обязательно** загрузи папки css и js целиком.
Если папок нет на GitHub — стили и 3D не загрузятся (будет белый экран с текстом).

## Что внутри

- Полноценная 3D-сцена на Three.js (плавающие объекты, частицы, освещение, тени)
- 7 больших разделов с подробным текстом
- Интерактивные вкладки, анимации при скролле
- Адаптивный дизайн
- Тёмная неоновая тема

## Локальный запуск

Просто открой index.html в браузере Chrome / Edge / Firefox.
